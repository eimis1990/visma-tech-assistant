# 🎬 Animation Demo Guide

## How to Experience the New Animations

### 1. **Start the Development Server**
```bash
npm run dev
```

### 2. **On Page Load** 👀
Watch for these animations in sequence:
- Header logo slides in from the left
- Sign-in button slides in from the right
- "Visma Tech Assistant" badge drops down
- Main title fades up smoothly
- "Try Now" button scales in
- Category cards cascade in one by one

### 3. **Move Your Mouse** 🖱️
- Notice the custom cursor (outer ring + inner dot)
- See the glow effect following your cursor
- Particles in the background floating gently

### 4. **Hover Over Cards** 🎯
- Cards follow your mouse with magnetic effect
- 3D tilt effect based on cursor position
- Smooth elastic spring-back when you move away

### 5. **Hover Over "Try Now" Button** 🔘
- Smooth scale-up animation
- Inner circle changes color
- Arrow shifts right

### 6. **Scroll Down** ⬇️
- Title section parallaxes (moves up and fades)
- Grid background shifts position
- Scroll indicator bounces and fades out
- Cards may reveal with stagger if below fold

### 7. **Watch the Background** 🌟
- 20 floating particles moving independently
- Grid pulsing subtly
- Glow effect following your cursor
- Overall breathing, living feel

## 🎨 Key Features to Notice

### Magnetic Cards
Move your mouse slowly over each card and watch them "lean" toward your cursor like they're attracted to it!

### 3D Depth
The cards rotate in 3D space (rotateX and rotateY) giving real depth perception.

### Smooth Transitions
All animations use professional easing curves for that premium feel.

### Responsive Design
- Custom cursor only shows on desktop (hidden on mobile)
- Touch-optimized for mobile devices
- Animations adapt to screen size
